# МСтрой тестовое

Дерево элементов хранилища на Vue 3, TypeScript, Vite и AG Grid Community. Данные загружаются из `json-server`, поддерживаются раскрытие/сворачивание групп, нумерация видимых строк и категории.

## Требования

- Node.js 20+
- npm

## Запуск

```bash
npm install
cp .env.example .env
```

В первом терминале запустить API:

```bash
npm run server
```

Во втором — приложение:

```bash
npm run dev
```

По умолчанию API доступен на `http://localhost:3000`, приложение — на адресе, который выведет Vite.

## Переменные окружения

| Переменная | Назначение | Значение по умолчанию |
| --- | --- | --- |
| `VITE_API_URL` | Базовый URL API | `http://localhost:3000` в dev, относительный путь в production |

Если `VITE_API_URL` не задан в production-сборке, запросы идут на текущий origin (`/items`).

## Структура

Проект организован по FSD:

- `src/entities/SomeEntity` — модель элемента, `TreeStore`, API и конфиг корня дерева.
- `src/features/ItemsTable` — таблица дерева: конфиг AG Grid, построение видимых строк и UI.
- `src/shared` — `BaseApi`, общие типы, конфиг API и глобальные стили.
- Тесты лежат в подпапках `__tests__` внутри соответствующего FSD-сегмента.

## Данные

Элемент имеет вид:

```ts
type SomeEntityItem = {
  id: number | string
  parent: number | string | null
  label: string
}
```

Корневые элементы ссылаются на `parent: null`; значение вынесено в константу `treeRootParentId`. Идентификаторы уникальны, числовые и строковые значения не смешиваются.

## TreeStore

- `getAll()` — все элементы в исходном порядке.
- `getItem(id)` — элемент по id.
- `getChildren(id)` — прямые дети в порядке добавления.
- `getAllChildren(id)` — все потомки в depth-first порядке, без самого элемента.
- `getAllParents(id)` — сам элемент и его предки от элемента к корню.
- `addItem(item)` — добавляет элемент; запрещает дубли id и элемент, являющийся родителем самому себе.
- `removeItem(id)` — удаляет элемент вместе с поддеревом.
- `updateItem(item)` — обновляет элемент; запрещает перенос в собственное поддерево.
- `setItems(items)` — заменяет данные; отклоняет дубли id до изменения состояния.

## Поведение таблицы

- При загрузке раскрываются корневые группы с детьми.
- «№ п/п» — номер видимой строки, пересчитывается при раскрытии и сворачивании.
- «Категория» вычисляется по наличию детей: `Группа` или `Элемент`.
- Счётчик в шапке показывает общее количество загруженных элементов, а не только видимых.
- AG Grid загружается отдельным чанком после получения данных.
- Раскрытие и сворачивание обновляют только затронутое поддерево, а грид получает изменения через `applyTransaction` с `addIndex`, чтобы новые строки вставлялись после группы, а не в конец списка; полная пересборка строк выполняется только при загрузке данных.
- `TreeStore` хранится в `shallowRef` и заменяется целиком при загрузке; мутации на месте не обновляют UI без замены ссылки или `triggerRef`.

## Производительность

- AG Grid и его конфигурация вынесены в отдельный ленивый чанк.
- Раскрытие/сворачивание не пересобирает весь список: обновляется только затронутое поддерево.
- Изменения передаются в AG Grid через `applyTransaction`, поэтому грид не диффает весь `rowData`.
- Номер строки вычисляется по `rowIndex`, а неизменённые объекты строк переиспользуются из кэша.
- Полная пересборка видимых строк выполняется только при загрузке или замене данных.
